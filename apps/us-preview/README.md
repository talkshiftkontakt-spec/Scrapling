# Us Our Day — Paper & Ink + Sunday Morning

Working interactive preview of directions **1** and **3** for the couples app **Us**.

## Run locally (in intelligent-bell or anywhere)

```bash
npm install
npm run dev
```

Open http://localhost:3200

Toggle at the top:
- **1 · Paper & Ink** — cream journal, Fraunces hero, sketch warmth
- **3 · Sunday Morning** — peach blush, dual partner colors, playful pills

Tap tasks to complete. Type a Daily Prompt note and Share.
