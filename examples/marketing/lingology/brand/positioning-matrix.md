# Positioning matrix — LingoLogy vs LingoTutor vs konkurenci

## 1. Dwie marki = dwa rynki (nigdy nie mieszaj CTA)

| | **LingoLogy** | **LingoTutor** |
|--|---------------|----------------|
| URL | lingology.pl | lingotutor.pl |
| Kupuje | Dorosły uczeń | Korepetytor |
| Obietnica | Mówię swobodniej | Prowadzę praktykę bez admin-piekła |
| CTA | Umów konsultację 0 zł | Zacznij za darmo |
| Kanał contentu | TikTok/Reels: bariera, praca, wstyd mówienia | TikTok/Reels/LinkedIn: admin, AI prep, rodzice |

**Zasada:** jeden post = jedna marka. Cross-link tylko świadomie (np. „uczniowie LingoLogy dostają App; korepetytorzy → LingoTutor”).

## 2. Mapa konkurencji

### vs LingoLogy (kursant)

| Gracz | Model | Siła | Luka vs LingoLogy |
|-------|-------|------|-------------------|
| **Preply** | Marketplace lektorów | Wybór, skala, brand | Brak jednej metody + bariery psychologicznej |
| **italki** | Marketplace + community | Native speakers, 150+ języków | Chaos wyboru; słaby „system między lekcjami” |
| **Cambly** | Native on-demand | 24/7 rozmowy | Mało głębokiej diagnozy bariery PL |
| **BUKI / e-korepetycje** | Ogłoszenia PL | Lokalność, cena, dzieci/szkoła | LingoLogy = dorośli + metoda + App, nie baza ogłoszeń |
| **Duolingo** (alt.) | Aplikacja / gamification | Nawyk, darmo | Nie rozwiązuje wstydu w mówieniu 1:1 |

**Pozycja LingoLogy:** premium-personal system dla dorosłych (nie marketplace, nie gra).

### vs LingoTutor (korepetytor)

| Gracz | Model | Siła | Luka vs LingoTutor |
|-------|-------|------|--------------------|
| **TutorCruncher** | CRM / ops dla firm tutoring | Billing, payroll, team | EN, firmowy; overkill dla solo PL; słaba pętla dydaktyczna AI |
| **BUKI / e-korepetycje** | Marketplace | Lead flow | Zero OS lekcji / pamięci ucznia |
| **Notes + WhatsApp + Calendar** | Status quo | 0 zł | Chaos, brak portalu, brak AI post-lekcji |

**Pozycja LingoTutor:** PL freemium OS praktyki językowej (AI + portal), nie marketplace i nie enterprise CRM.

## 3. Kiedy którą markę promować

| Sytuacja | Marka |
|----------|-------|
| Content o lęku przed mówieniem, pracy, CV | LingoLogy |
| Content o zyskanej godzinie adminu, rodzicach, prep | LingoTutor |
| Współpraca z korepetytorami / affiliates | LingoTutor najpierw |
| Leady konsultacji 1:1 | LingoLogy |
| Product hunt / SaaS crowd | LingoTutor |
| Local PL education creators | obie, ale osobne konta lub jasne serie |

## 4. Shared ecosystem (opcjonalny narrative)

```
LingoLogy  = front dla ucznia (doświadczenie nauki)
LingoTutor = OS dla nauczyciela (operacje + AI dydaktyczne)
```

Używać wspólnego story **tylko** gdy budujesz holding/ekosystem. Na growth stage: **osobne kanały / osobne serie**.
