# Brand brief — LingoLogy (lingology.pl)

Źródło: scrape `scrapes/lingology/` (2026-07-15).

## One-liner

Angielski online dla dorosłych — korepetycje 1:1 nastawione na mówienie, z diagnozą bariery i planem między lekcjami w LingoLogy App.

## Produkt

| Element | Fakt ze strony |
|---------|----------------|
| Format | Lekcje online 1:1 |
| Cena wejścia | Od **80 zł / 55 min** |
| Lead magnet | **Konsultacja 0 zł · 20 min** |
| Differentiator | Diagnoza bariery językowej + plan tygodniowy + App między spotkaniami |
| Założyciel | Kuba (psychologia UJ) — ton osobisty, partnerski |

## Idealny klient (persona)

- Dorosły **25–45 lat** (FAQ: nie dzieci, nie nastolatki)
- Zna gramatykę „w głowie”, **boi się / blokuje przy mówieniu**
- Potrzebuje angielskiego do pracy, rozmów kwalifikacyjnych, po przerwie, konwersacji
- Ma dość kursów, po których „nic się nie zmienia”
- Gotów do regularności, jeśli widać plan między lekcjami

## Job to be done

> „Chcę wreszcie mówić swobodniej po angielsku — bez wstydu i bez zaczynania od zera co tydzień.”

## Problemy, które adresujemy

1. Blokada / stres w mówieniu (nie brak talentu)
2. Chaotyczna nauka — materiał znika po lekcji
3. Marketplace’y (Preply/italki): wielu lektorów, brak systemu wokół jednej metody
4. Aplikacje (Duolingo/Cambly): dużo aktywności, mało głębokiej pracy nad barierą

## USP (kolejność w komunikacji)

1. **Mówienie first** — realne sytuacje, nie teoria
2. **Diagnoza bariery** — test + plan pod konkretny problem
3. **System między lekcjami** — App + plan tygodniowy
4. **Dorosły kontekst** — praca, rozmowy, przerwa w nauce
5. **Niska bariera startu** — konsultacja 0 zł / 20 min

## Ton głosu

- Po polsku, konkretnie, bez guru-energy
- Empatyczny wobec wstydu przy mówieniu
- Autorytet metody („system”), nie „magiczna aplikacja”
- Osobisty (Kuba), ale nie infantylny

## Do / Don’t

| Do | Don’t |
|----|-------|
| Mów o blokadzie, planie, App, konsultacji 0 zł | Obiecuj native w 30 dni |
| CTA: umów konsultację / zrób test bariery | Mieszaj z ofertą LingoTutor (inna persona) |
| Social proof z opinii uczniów | Porównuj ceną „jesteśmy najtansi” |
| Angle: psychologia bariery + praktyka | Angle: „tysiąc lektorów do wyboru” |

## CTA hierarchy

1. Umów konsultację (0 zł) → https://www.lingology.pl
2. Test bariery językowej → `/test-bariery-jezykowej`
3. Test językowy → `/test-jezykowy`
4. Wejdź do aplikacji / poznaj App

## Competitive frame (1 zdanie)

Marketplace daje lektora. LingoLogy daje **system**: diagnozujesz barierę, mówisz na lekcji, ćwiczysz według planu w App między spotkaniami.
