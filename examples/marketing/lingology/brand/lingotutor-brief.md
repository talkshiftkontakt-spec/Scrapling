# Brand brief — LingoTutor (lingotutor.pl)

Źródło: scrape `scrapes/lingotutor/` (2026-07-15).

## One-liner

System operacyjny praktyki korepetytora językowego — briefing AI rano, pętla po lekcji, pamięć ucznia i portal. 45 minut adminu → 2 minuty.

## Produkt

| Element | Fakt ze strony |
|---------|----------------|
| Audience | Korepetytorzy językowi (B2B solo / mikro-praktyka) |
| Core loop | Briefing rano → lekcja z prep → podsumowanie głosowe 2 min |
| Features | Uczniowie/pakiety, płatności, kalendarz+Google, plany AI, portal ucznia/rodzica |
| Pricing | **Start 0 zł** · **Pro 59,99 zł/mies.** · **Pro+ 99,99 zł/mies.** |
| CTA | Zacznij za darmo |

### Plany (skrót)

- **Start (0 zł):** ∞ uczniów, limity AI niskie, 3 pętle post-lekcji/mies., portal ucznia/rodzica
- **Pro (59,99):** nielimitowane generacje planów/celów, 35 planów lekcji, 50 pętli AI/mies.
- **Pro+ (99,99):** 100 planów, nielimitowane pętle AI, support 8–22 + chatbot

## Idealny klient (persona)

- Korepetytor języka (głównie angielski) z **5–40 uczniami**
- Traci czas na prep, notatki, wiadomości do rodziców, śledzenie płatności
- Ma Excel / Notes / WhatsApp / Google Calendar zamiast jednego systemu
- Chce wyglądać profesjonalnie wobec ucznia i rodzica (portal)
- Polska / PL-speaking — cennik w PLN

## Job to be done

> „Chcę prowadzić korepetycje jak firmę: wiedzieć, czego dziś uczyć, co było na ostatniej lekcji i nie siedzieć godzinę po każdym spotkaniu przy adminie.”

## Problemy, które adresujemy

1. Admin zjada marżę (prep + notatki + follow-up ≈ 45 min)
2. Brak ciągłości dydaktycznej (pamięć ucznia rozproszona)
3. Marketplace’y (BUKI, e-korepetycje) dają leady, nie OS praktyki
4. TutorCruncher / CRM-y dla firm tutoringowych — overkill / EN / drogo dla solo PL

## USP

1. **OS nauczania**, nie tylko kalendarz
2. **Pętla post-lekcji głosem** (2 min → profil + HW + wiadomość do rodzica)
3. **Pamięć dydaktyczna ucznia** (CEFR, cele, słabe strony) → plany AI
4. **Portal ucznia i rodzica w każdym planie** (w tym free)
5. **Start za 0 zł** — freemium PL-native

## Ton głosu

- B2B-lite: konkretne minuty zaoszczędzone, nie „zrewolucjonizuj edukację”
- AI jako asystent adminu i dydaktyki, nie zastępowanie nauczyciela
- Profesjonalny, spokojny, produktowy

## Do / Don’t

| Do | Don’t |
|----|-------|
| CTA: zacznij za darmo / cennik | Obiecuj „AI nauczy za Ciebie” |
| Angle: 45 min → 2 min adminu | Mieszaj z LingoLogy (to kursanci, nie tutorzy) |
| Porównuj do chaosu WhatsApp+Notes | Atakuj Preply jako „zły marketplace” bez niuansu |
| Pokazuj portal rodzica jako trust | Obiecuj lead generation (to nie marketplace) |

## CTA hierarchy

1. Zacznij za darmo → https://www.lingotutor.pl/welcome
2. Cennik → https://www.lingotutor.pl/cennik
3. Login dla istniejących → `/login`

## Competitive frame (1 zdanie)

Marketplace daje uczniów. CRM firmowy zarządza zespołem. LingoTutor jest **systemem operacyjnym jednej praktyki językowej** — od briefingu rano do wiadomości dla rodzica po lekcji.
