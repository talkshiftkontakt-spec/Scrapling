# Checklista przed wdrożeniem (anty-AI-slop)

Odznacz zanim pójdziesz dalej.

## Fonty
- [ ] H1 nie jest w Inter/Roboto/Arial
- [ ] Display i body to różne role (inna rodzina LUB mocno inny optical size)
- [ ] Mono używane punktowo (composer / ID / kod), nie dekoracyjnie wszędzie
- [ ] Licencja fontów sprawdzona pod web embedding

## Kolor
- [ ] Jest **max 1** akcent marki w chrome
- [ ] Brak purple→indigo mesh jako domyślnego tła
- [ ] Brak warm-cream + terracotta „editorial AI” zestawu
- [ ] Dark mode tylko jeśli to świadoma decyzja (nie „bo AI”)

## Layout pierwszego viewportu
- [ ] Brand/marka jest hero-level (nie tylko w nav)
- [ ] Jedna kompozycja, nie mini-dashboard
- [ ] Brak kart w hero
- [ ] Brak paska ikon / stats / badge naklejek na media
- [ ] Jeden dominant visual (produkt / foto / prompt / ilustracja)

## Komponenty
- [ ] Drabinka radiusów (nie wszystko `9999px`)
- [ ] Cienie: max 1 miękka warstwa
- [ ] CTA: solid + ghost, ta sama wysokość
- [ ] Logo cloud monochrome (jeśli w ogóle)

## Motion
- [ ] 2–3 intencje, nie continuous noise
- [ ] Brak glow pulse na każdym przycisku

## Test końcowy
- [ ] Zasłonięte logo → strona NIE wygląda jak 20 innych AI SaaS
- [ ] Wybrany **jeden** kierunek z `04-kierunki/` (ew. świadomy hybrid B+D lub A+D)
