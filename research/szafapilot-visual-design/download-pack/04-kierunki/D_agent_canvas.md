# Kierunek D — Agent Canvas

**Mood:** AI-native, interaktywny, nowoczesny 2026 — **bez** rainbow mesh slopu.  
**Kiedy:** rdzeniem produktu jest composer / agent / automatyzacja.

## Kolor
- Canvas: Soft Instrument off-white **albo** warm dark `#12110F`
- Prompt bar: surface z 1px border; focus ring = 1 akcent
- Accent tylko na Send/Generate (np. ink black lub jeden brand)
- Mesh/aurora: **opcjonalnie**, niska saturacja, za treścią, nie jako brand

## Typografia
- Display: Satoshi / Switzer
- Meta agenta / thinking: mono 12–13px
- H1 nie musi być ogromny — composer jest bohaterem

## Layout
- Prompt-as-hero (input ≥56px wysokości, duży radius)
- Po bokach opcjonalnie floating artifact/mockupy
- Unikaj drugiego dużego CTA obok composera (konkurencja)

## Interaction
- Focus state composera
- Thinking indicator
- Subtelny pulse border (nie disco gradient)

## Referencje
Lovable (struktura, nie kopiuj mesh 1:1), Relume, Retool, Framer Agent panel
