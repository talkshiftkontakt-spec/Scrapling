# Kierunek A — Precision Void

**Mood:** spokojny, techniczny, high-signal, „pro tool”.  
**Kiedy:** workflow / automation / seller ops z naciskiem na precyzję.

## Kolor
- Canvas: warm near-black `#0F0E0C` (nie czysty `#000` — mniej Vercel-clone)
- Text: `#F5F5F4` / muted `#A1A1AA`
- Accent (1): chłodny teal `#2DD4BF` **albo** stale blue `#60A5FA` — tylko status/AI/active
- CTA primary: biały fill / czarny text
- CTA secondary: 1px border `rgba(255,255,255,0.18)`

## Typografia
- Display + body: Cabinet Grotesk / Satoshi / Geist
- Mono: Geist Mono lub IBM Plex Mono
- H1: 48–64px, tracking −0.03em…−0.05em

## Layout
- Hero: left-aligned H1 + dual CTA + product window
- Głębia: 1px border + zmiana wartości koloru, nie heavy shadow
- Pierwszy viewport: bez ikonek-feature, bez stats strip

## Interaction
- Fade-in stage
- Status micro-motion (spinner / pulse tylko na AI)
- Bez mesh rainbow, bez glow na buttonach

## Referencje
Linear, Cursor (struktura), Framer (fidelity), Supabase (dyscyplina akcentu), Vercel (tylko kontrast — nie kopiuj void 1:1)
