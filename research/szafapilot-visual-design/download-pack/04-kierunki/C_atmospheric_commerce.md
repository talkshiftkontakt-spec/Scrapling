# Kierunek C — Atmospheric Commerce

**Mood:** filmowy, ludzki, marketplace / seller confidence.  
**Kiedy:** Szafapilot ma czuć się jak narzędzie sprzedawców/rynku, nie jak IDE.

## Kolor
- Hero: fotografia / ilustracja pełnoekranowa + dark overlay `rgba(0,0,0,0.35–0.55)`
- Type na media: biały
- Accent CTA: jeden mocny (indigo `#4F46E5` / brand green) — reszta neutral
- Sekcje poniżej: czarny stage z dużym radiusem 24–40px

## Typografia
- Display grotesque: Satoshi / Neue Haas-like / Switzer
- Duży H1 na media, tracking lekko ujemny
- Nav: mała, biała, niski weight

## Layout
- Full-bleed hero
- CTA cluster: solid inverted + ghost/outline
- Produkt jako floating card NA zdjęciu (Partiful pattern) albo stage pod foldem

## Interaction
- Lekki ken-burns / parallax (subtelny)
- Play affordance jeśli video
- Glass tylko na input/CTA bar, nie na całej stronie

## Referencje
Mercury, Shopify, Partiful (kontrola energii), Loom (media stage)
